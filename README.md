# Cvent Plugin Marketplace

Plugin marketplace for [Claude](https://claude.ai). This repository contains skill
definitions published by Cvent that extend your AI agent with Cvent workflows and tooling.

## Contents

This marketplace publishes skill definitions in Markdown and plugin configuration in JSON.
Skills describe Cvent tools and workflows that your AI agent can use on your behalf.
