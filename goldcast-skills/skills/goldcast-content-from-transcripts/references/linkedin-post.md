# LinkedIn post

Read this after you've chosen one angle (SKILL.md Step 5). The fidelity rules in Step 6 apply to everything here.

## Structure

1. **Hook (first 2 lines).** LinkedIn shows roughly the first 200 characters before "see more", so the hook has to stand alone. Lead with the tension, surprise, or sharpest insight from the notes, not with the event. Don't open with "We're thrilled to share" or similar filler.
2. **Body (3 to 5 short paragraphs or lines).** One idea per line, blank line between. Deliver the value of the angle here, so a reader gets something even if they never click. Use at most one verbatim quote, short and attributed (name, title, company from `list_speakers`).
3. **Close with one CTA.** Default is to watch the recording, using the on-demand link or `[LINK: on-demand recording]`. If the user gave a different goal, use that. One CTA only.
4. **Hashtags (optional).** 0 to 3, only if the user's brand guidance uses them. Don't invent a campaign hashtag.

## Length and format

- Target 120 to 220 words. Hard ceiling 300 words (the platform limit is 3,000 characters, but shorter wins).
- Plain text. No markdown headings, no bold. Light use of line breaks. Emojis only if the user's brand voice uses them, and then at most one or two.
- Tagging: mark speaker handles as `[TAG: speaker name]` for the user to fill in. Don't guess handles.

## Multiple sessions

One post that follows the through-line across sessions, not a stack of recaps. If the user wants one post per session, vary the hook for each so they don't read as a series of copies.

## Deliver

- The post, ready to copy.
- A second hook option on its own line below it (labeled "Alternate hook") so the user can choose.
- Anything uncertain goes in `[VERIFY: ...]` and in Review notes.
