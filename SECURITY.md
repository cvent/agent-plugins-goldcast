# Security Policy

## Reporting a Vulnerability

To report a security vulnerability in this repository or in any Cvent product or service,
use Cvent's Vulnerability Disclosure Program:
<https://www.cvent.com/en/event-management-software/report-security-vulnerability>.
Please include a description of the issue, the steps to reproduce it, and the potential
impact.

Do not open a public GitHub issue for a security vulnerability.

We aim to respond to security reports within two business days and to resolve confirmed
vulnerabilities within a timeframe appropriate to their severity.
